Privacy policy · 隐私政策

数据如何处理。

本政策说明 MacBook DA Sync 个人桌面同步工具和此说明网站的数据处理方式。

生效日期：2026-10-26。
Effective date: 2026-10-26.

1. 应用用途与适用范围

本工具供其 Google 账号所有者自用，在本机 Mac 与所有者的 Google Drive 之间复制选定报告，不提供公众注册服务。本政策不替代 Google、GitHub 或所有者另行使用的其他服务的政策。

This personal utility copies selected reports between its owner's Mac and Google Drive. It has no public sign-up service. This policy does not replace the policies of Google, GitHub or other services the owner separately uses.

2. 处理哪些数据

  • 所有者选择同步的报告内容及文件名。
  • 用于核验的文件大小、校验值、传输结果和时间。
  • 完成无人值守同步所必需的 Google OAuth 授权信息。

上传器筛除原件目录、原始录制流、凭据和私钥，不把授权信息作为报告内容上传。此说明网站不收集报告、账号密码或授权信息。

The utility handles selected report contents and names, verification metadata, transfer results and timestamps, and the OAuth authorization information necessary for unattended synchronization. Originals, raw streams, credentials and private keys are excluded from report uploads. This information website does not collect reports, passwords or authorization information.

3. 数据用途和存储位置

报告用于所有者要求的同步与复核。本地报告副本与传输回执保存在 Mac；选定的报告副本保存在所有者的 Google Drive MacBook 文件夹。OAuth 客户端信息和授权信息放在上传源之外、具有受限文件权限的本机配置中。日志会进行凭据脱敏。

Data is used to perform and verify the owner's requested synchronization. Local reports and transfer receipts remain on the Mac; selected copies are stored in the owner's MacBook folder in Google Drive. OAuth client and authorization information is stored in local configuration with restricted file permissions outside the upload source. Logs are sanitized for credentials.

4. 权限范围与操作边界

Google Drive OAuth 权限本身覆盖账号的 Drive 文件，允许查看、修改、创建与删除。同步器通过固定目标目录及命令白名单，将自己的操作限制为 MacBook 文件夹内的复制和核验；不据此宣称 Google 已实施仅单目录授权。

The Drive OAuth scope permits viewing, editing, creating and deleting account Drive files. The utility's fixed destination and command allowlist restrict its own operations to copying and verification within the MacBook folder. This is not a claim that Google enforces folder-only authorization.

5. 共享与其他用途

所选报告通过 Google API 传给 Google Drive。此工具不出售数据，不用于广告，也不将报告内容发送给独立的应用服务器或用于模型训练。所有者若随后把云端报告分享给其他人或服务，由所有者另行决定。

Selected reports are transmitted to Google Drive through Google's API. The utility does not sell data, use it for advertising or model training, or send report content to a separate application server. Any later sharing with people or services is controlled separately by the owner.

6. 保留、停止与撤销

所有者可停止 macOS 定时任务，在 Google 账号中撤销应用授权，并移除本机配置。停止同步或撤销授权不会自动移除已经保存的报告。工具不传播本地删除；既有报告和研究原件仍按所有者的留存安排管理。

The owner can stop the macOS scheduler, revoke the application's Google authorization, and remove its local configuration. Stopping or revoking access does not automatically remove saved reports. The utility does not propagate local deletions or replace existing retention arrangements.

7. 这个说明网站

网站只提供静态说明和隐私政策，不设表单、登录、广告、分析脚本或嵌入式第三方资源，不主动设置 Cookie。采用 GitHub Pages 托管；GitHub 可能为网站运行和安全记录访问者 IP 等访问日志，其处理方式以 GitHub 隐私声明为准。

This static information website has no forms, sign-in, advertising, analytics scripts or embedded third-party resources, and does not itself set cookies. This website is hosted by GitHub Pages. GitHub may record visitor IP addresses and access logs for operation and security under its own privacy statement.

GitHub 隐私声明 / GitHub Privacy Statement

8. 联系与政策更新

如需联系应用所有者，请使用 Google OAuth 权限页面所列的支持联系方式。数据处理方式发生变化时，应在实施变化前更新本政策。

Contact the app owner through the support contact shown on the Google OAuth consent screen. This policy must be updated before changes to the utility's data handling are applied.
